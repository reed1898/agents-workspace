# 交易记录应用 - 需求文档

## 项目概述

**项目名称**: Trading Notes（交易笔记）

**项目目标**: 开发一款面向个人投资者的交易记录和复盘应用，支持多市场（加密货币、美股、A股、港股）的交易同步、持仓管理、交易计划记录和纪律检查。

**目标用户**: 有交易系统和纪律要求的个人投资者

**应用形态**: Web 应用（浏览器访问）

---

## 核心功能需求

### 1. 交易数据同步

#### 支持市场
- **加密货币**: 币安（Binance）
- **美股**: 盈透证券（Interactive Brokers）
- **A股**: 待定券商
- **港股**: 待定券商

#### 同步方式
- **优先方式**: API 自动同步（定期或手动触发）
- **备用方式**: CSV/Excel 文件导入（不支持 API 的平台）

#### 同步内容
- 历史交易记录（买入/卖出/加仓/减仓）
- 交易时间、价格、数量
- 手续费和其他费用
- 当前持仓信息

---

### 2. 持仓管理

#### 持仓展示
- **实时市值**: 需要接入行情数据
- **浮动盈亏**: 金额和百分比
- **持仓周期**: 持有天数
- **平均成本价格**: 加权平均成本
- **持仓占比**: 按市场/资产类型分布

#### 分组管理
- 支持账户分组（如：长期投资账户、短线交易账户）
- 跨市场的资产汇总视图
- 灵活的分组标签系统

#### 历史持仓
- 已清仓标的的历史记录
- 历史盈亏统计
- 持仓时长分析

---

### 3. 交易计划与记录

#### 开仓计划

##### 建仓理由
- 符合交易系统的哪些条件
- 技术面/基本面分析要点
- 关键信号和触发条件
- 支持附件上传（图表截图等）

##### 止损止盈设置
- 止损价格和比例
- 止盈目标（可设置多级目标）
- 移动止损策略
- 止损触发条件

##### 风险评估
- 风险等级（低/中/高）
- 预期盈亏比
- 最大可接受亏损金额
- 仓位大小规划

#### 操作记录
- 建仓/加仓/减仓/清仓的每一次操作
- 每次操作的理由说明
- 操作时的情绪状态记录
- 操作时间戳

---

### 4. 交易纪律检查

#### 止损执行检查
- 是否按计划止损
- 止损延迟或提前情况
- 未执行止损的原因记录
- 止损执行率统计

#### 加减仓原因追踪
- 每次加减仓是否符合计划
- 冲动交易标记
- 计划外操作统计

#### 情绪记录
- 贪婪/恐惧/冷静等情绪标签
- 情绪对交易结果的影响分析
- 情绪模式识别

#### 偏离统计
- 统计偏离交易计划的次数和比例
- 偏离交易的盈亏情况对比
- 纪律遵守度趋势分析

---

### 5. 数据分析与可视化

#### 收益率分析
- 总收益率曲线（按时间维度）
- 按市场维度的收益对比
- 按标的/品种的收益排名
- 胜率统计（盈利交易占比）
- 最大回撤分析

#### 交易纪律分析
- 纪律遵守度评分
- 止损执行率
- 偏离交易的影响分析
- 情绪交易的盈亏对比
- 改进建议生成

#### 持仓可视化
- 仪表盘总览（总资产、今日盈亏、持仓分布）
- 资产配置饼图/树图
- 各市场持仓对比
- 持仓集中度分析

#### 交易复盘笔记
- 每笔交易的复盘总结
- 成功/失败经验提取
- 交易系统优化建议
- 复盘标签分类

---

## 非功能性需求

### 数据安全与隐私

#### 用户认证
- 账号密码登录
- 密码强度要求
- 可选：第三方登录（后期扩展）

#### API 密钥安全
- 交易所 API 密钥加密存储
- 使用行业标准加密算法（Fernet）
- 密钥定期轮换提醒

#### 数据备份
- 每日自动备份数据库
- 支持手动触发备份
- 备份数据加密存储

#### 数据导出
- 支持导出全部交易数据
- 支持 CSV、Excel、JSON 格式
- 导出数据脱敏处理

### 性能要求
- 页面加载时间 < 3秒
- API 响应时间 < 500ms
- 支持至少 10万条交易记录
- 图表渲染流畅（60fps）

### 兼容性
- 支持现代浏览器（Chrome、Firefox、Safari、Edge）
- 响应式设计（适配桌面和平板）
- 移动端友好（后期优化）

## 用户场景示例

### 场景 1: 开仓前计划
1. 用户发现交易机会，符合交易系统
2. 在应用中创建交易计划
3. 填写建仓理由、技术分析要点
4. 设置止损止盈价格
5. 进行风险评估（盈亏比、最大亏损）
6. 保存计划，等待开仓

### 场景 2: 执行交易
1. 在交易所执行买入操作
2. 应用自动同步交易记录
3. 系统自动关联到交易计划
4. 记录操作理由和情绪状态
5. 系统检查是否符合计划

### 场景 3: 持仓监控
1. 用户打开持仓页面
2. 查看实时市值和浮动盈亏
3. 对比当前价格和止损止盈设置
4. 查看持仓周期和成本价格
5. 决定是否需要调整计划

### 场景 4: 止损执行
1. 价格触及止损位
2. 用户执行止损卖出
3. 应用记录止损操作
4. 系统检查执行时机是否准确
5. 标记纪律遵守情况
6. 触发复盘提醒

### 场景 5: 交易复盘
1. 交易完结后，用户进入复盘页面
2. 查看完整的交易过程（计划 vs 实际）
3. 分析盈亏原因
4. 记录经验教训
5. 更新交易系统规则

## 后续扩展方向

1. **交易系统编辑器**: 可视化定义交易系统规则，自动检查开仓条件
2. **回测功能**: 基于历史数据测试交易策略有效性
3. **移动端 App**: 独立的 iOS/Android 应用
4. **智能提醒**: 价格预警、计划提醒、纪律违规提醒
5. **社区功能**: 匿名分享交易心得（去隐私化）
6. **AI 辅助**: 使用 LLM 分析交易模式和提供改进建议
7. **多用户版本**: 团队协作、导师学员模式
8. **交易日志**: 每日交易日记、市场观察笔记

## 4) 风险提示（安全 / 维护 / 依赖）

- **安全**
  - 涉及外部抓取或执行代理的 skill，必须限制写权限范围，避免误操作越权。
  - DB 类 skill 坚持只读账号和最小权限，防止误改生产数据。

- **维护**
  - 高下载量不等于高稳定性；建议先在小任务灰度，再纳入标准工作流。
  - 子代理并行会增加流程复杂度，需配套日志与回滚约定。

- **依赖**
  - 第三方服务（如 X 抓取中间层）可能波动，建议准备降级路径（本地缓存/备用源）。
  - GitHub/外部 API skill 依赖 token 与网络可用性，需设健康检查与失效告警。

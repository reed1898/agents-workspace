## Slide 2: 什么是 OpenClaw？

**一句话定义**
运行在本地电脑上的 AI 助手，能像你一样操作电脑

**核心特点**
- 🏠 **本地运行** — 数据不出本机，隐私可控
- 🔧 **工具调用** — 能执行命令、操作文件、调用 API
- 🧠 **持续学习** — 通过 Memory 文件记住你的偏好
- 🚀 **技能扩展** — 通过 Skills 不断获得新能力

---

## Slide 3: "活人感" — 这不是一个聊天机器人

**传统 AI 助手**
- 问一句答一句
- 每次对话从零开始
- 被动等待指令

**OpenClaw 的"活人感"**
- ✅ **主动** — 通过 Cron 定期检查任务（Moltbook、邮件、提醒）
- ✅ **学习力强** — 安装 Skills 即可掌握新技能
- ✅ **技能丰富** — 已配置 40+ Skills（Gmail、Calendar、股票分析...）
- ✅ **自我进化** — 根据你的反馈更新 MEMORY.md
- ✅ **实时响应** — 通过 Telegram 随时 reachable

**关键区别**: 它不只是回答问题，而是**持续存在于你的工作流中**

## Slide 7: 核心感受 — 本地 vs 云端

| 维度 | OpenClaw (本地) | Manus (云端) |
|------|----------------|--------------|
| **能力边界** | 你的电脑能做什么，它就能做什么 | 受限于云端沙箱 |
| **个性化** | 深度理解你的文件、习惯、偏好 | 通用型，无持久记忆 |
| **隐私安全** | 数据不出本机 | 上传云端，存在泄露风险 |
| **响应速度** | 本地执行，低延迟 | 网络依赖 |
| **成本** | 用你的电和算力 | 按量付费 |

**关键洞察**: 本地 AI 像"一个人坐在你电脑前帮你干活"，云端 AI 像"远程客服"

## Slide 8: 核心感受 — 交互方式的变革

### 6.1 GUI/Command → 对话

**过去**
```bash
# 查股票
curl https://api.binance.com/api/v3/ticker/price?symbol=BTCUSDT
# 解析 JSON...
```

**现在**
```
"帮我查一下 BTC 最新价格，顺便分析一下走势"
```

**变化**: 意图表达 → 结果获取，跳过中间步骤

## Slide 9: 核心感受 — 数据形式的演进

### 6.2 结构化数据 → 自然语言

**过去**: SQL / JSON / XML / Protobuf
```json
{
  "symbol": "BTC",
  "price": 69064,
  "change_24h": -1.58
}
```

**现在**: 自然语言
```
"BTC 现在 $69,064，24小时跌了 1.58%，市场情绪偏谨慎"
```

**意义**: 技术门槛降低，人机交互更自然

## Slide 10: 核心感受 — 效率对比

### 6.3 人与人 vs BOT 与 BOT

**人与人协作**
- 需要同步时间
- 信息传递有损耗
- 情绪/状态影响效率

**BOT 与 BOT 协作**
- 7x24 不间断
- API 级精准对接
- 无情绪干扰

**新场景**: 你的 OpenClaw 可以和同事的 OpenClaw 直接协作
- 自动同步日程
- 共享知识库
- 协同文档编辑

## Slide 11: 核心感受 — 安全与限制

### 6.4 安全性问题
- AI 能执行命令 → 潜在风险
- 需要权限管理（只读 vs 可写 vs 可执行）
- 参考: [X 上的安全讨论](https://x.com/bitfish/status/2020367776137822536)

### 6.5 国内的墙
- 依赖 OpenAI/Claude API → 需要稳定网络
- 替代方案: 本地模型（Ollama）、国内 API

## Slide 12: Software is Dead？

### 观点
当 AI 能直接理解意图并执行，我们还需要那么多 App 吗？

### 预测 
- **App 角色转变**: 从"功能入口"变成"数据/服务接口"
- **交互变革**: 用户不再打开 App，而是通过 AI 调用 App 的能力
- **界面演进**: "对话即界面"（CUI）取代 GUI

### 意义
这可能是继 PC → Mobile 之后的下一次计算平台变革

## Slide 13: 终极问题 — 如何赚钱？

### 新商业模式的思考

**参考**: [Software is Dead, What Now?](https://www.youtube.com/watch?v=4uzGDAoNOZc)

**可能的模式**
1. **Agent 即服务** — 定制化 AI Agent 开发
2. **技能市场** — Skills 付费下载（类似 App Store）
3. **Agent 经济** — AI 之间的服务交易
4. **效率咨询** — 帮助企业搭建 AI 工作流
5. **数据价值** — 个人知识库的货币化

**核心转变**: 从"卖软件"到"卖能力"

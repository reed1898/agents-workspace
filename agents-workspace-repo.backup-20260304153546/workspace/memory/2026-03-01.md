# 2026-03-01 - 排障记录

## 问题: Telegram/Discord bot 回复 503 错误

### 现象
Telegram channel 的 bot (@reed_oc_bot) 回复消息时返回:
> 503 Service temporarily unavailable. The system has attempted to process your request with all available Claude Console accounts.

Discord channel 同样受影响,无法回复消息。

### 根因
主模型 `cc-club-claude/claude-opus-4-6` 通过第三方共享池 `https://claude-code.club/api` 调用 Claude API。该池是多用户共享的 Claude Console 账号池,当所有账号被占满或达到速率限制时,返回 503。

### 解决过程

1. **配置 fallback 模型**
   - 先尝试配置 `openai-codex/gpt-5.2-codex` 作为 fallback,但 failover 也失败(FailoverError)
   - 改为配置 `kimi-coding/k2p5` 作为 fallback,成功生效
   - 命令:
     ```bash
     openclaw models fallbacks add kimi-coding/k2p5
     openclaw models fallbacks list  # 验证
     ```

2. **重启 gateway**
   - 修改 fallback 后需要重启 gateway 才能生效
   - 遇到 gateway token mismatch 问题,需要先 uninstall 再 install:
     ```bash
     openclaw gateway stop
     openclaw gateway uninstall
     openclaw gateway install --force
     openclaw gateway start
     ```
   - 如果 `gateway start` 不生效,可用 `launchctl kickstart gui/501/ai.openclaw.gateway`

3. **验证**
   - 发送测试消息: `openclaw message send --channel telegram -t 869269685 -m "测试"`
   - 检查日志: `tail /Users/rain/.openclaw/logs/gateway.log`
   - 检查错误: `tail /Users/rain/.openclaw/logs/gateway.err.log`
   - 运行时日志: `/tmp/openclaw/openclaw-2026-03-01.log`

### 关键经验

1. **cc-club-claude 503 是上游共享池资源耗尽**,不是本地配置问题。另一台机器可能因时间差而可用。

2. **fallback 配置更改是热加载的** — gateway 会检测 config 变化并动态应用(`config change applied: agents.defaults.model.fallbacks`),但重启更可靠。

3. **gateway token mismatch** 只影响 CLI 探测命令(`channels status`, `gateway health`),不影响 Telegram/Discord bot 的实际收发消息。修复方法: `openclaw gateway install --force`。

4. **`openclaw message send` 是从 bot 向外发消息**,不会触发 bot 自动回复。要测试 bot 回复,需要用户在 Telegram/Discord 直接给 bot 发消息。

5. **常用排障命令**:
   - `openclaw channels status` — 查看 channel 连接状态
   - `openclaw channels logs --channel telegram` — 查看 channel 日志
   - `openclaw models fallbacks list` — 查看当前 fallback 配置
   - `openclaw gateway health` — 检查 gateway 健康状态

6. **配置文件位置**:
   - 主配置: `~/.openclaw/openclaw.json`
   - 模型配置: `~/.openclaw/agents/main/agent/models.json`
   - 认证配置: `~/.openclaw/agents/main/agent/auth-profiles.json`
   - LaunchAgent: `~/Library/LaunchAgents/ai.openclaw.gateway.plist`

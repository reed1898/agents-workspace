HN AI 文章简报：

1) [Gemini 3.1 Pro（Model Card）](https://deepmind.google/models/model-cards/gemini-3-1-pro/)
- 摘要：Google 发布 Gemini 3.1 Pro 模型卡，定位为 Gemini 3 系列中的高复杂度任务版本，强调原生多模态（文本/图像/音频/视频/代码仓）与长上下文（最高 1M token）。文档披露其在推理、长上下文、Agent 工具使用等维度有显著提升，并给出与多家前沿模型的对比评测。对企业团队而言，这不是“新功能补丁”，而是面向复杂工作流的能力迭代。
- 亮点：若你有多模态+长流程任务（代码审查、知识库问答、视频理解），可直接把 3.1 Pro 作为新基线做 A/B 评测。

2) [Nvidia 与 OpenAI 放弃 1000 亿美元未完成交易，转向 300 亿美元投资（FT）](https://www.ft.com/content/dea24046-0a73-40b2-8246-5ac7b7a54323)
- 摘要：HN 热议焦点是 AI 基础设施与资本合作模式的“降杠杆重构”：从超大规模绑定交易，转向更可执行的分阶段投资。该变化通常意味着双方在产能、治理、回报周期或监管约束上重新平衡。原文存在订阅墙，公开细节有限。
- 亮点：信息有限，保守判断——AI 大厂合作正从“一次性巨额押注”转为“分期+可回撤”的资金与产能安排。

3) [Consistency Diffusion Language Models：最高 14x 推理加速](https://www.together.ai/blog/consistency-diffusion-language-models)
- 摘要：文章提出对扩散语言模型（DLM）做后训练改造，目标是同时解决两大瓶颈：高步数推理开销和缓存利用困难。核心思路是通过轨迹蒸馏与 block-wise KV cache，使更少采样步数下仍维持质量。若结果可复现，意味着非自回归路线在吞吐与成本上更接近生产可用。
- 亮点：可执行价值很直接——高并发生成场景可优先试验该范式，重点验证“延迟/成本下降是否不牺牲质量”。

4) [Anthropic：将前沿网络安全能力开放给防守方（Claude Code Security）](https://www.anthropic.com/news/claude-code-security)
- 摘要：Anthropic 发布 Claude Code Security 研究预览版，面向代码库做漏洞发现并生成补丁建议，但保留“人工审批”闭环。其方法不再主要依赖规则匹配，而是让模型做代码语义与数据流推理，再经过多阶段复核降低误报。定位上更像“安全研究员副驾”，而不是传统扫描器替代品。
- 亮点：对安全团队的可执行点是先在高风险仓库小范围试点，衡量“高危漏洞检出率提升”与“误报率变化”。

5) [Cord：Coordinating Trees of AI Agents](https://www.june.kim/cord)
- 摘要：该项目主张将多 Agent 协作从“预先硬编码流程图”转向“运行时动态任务树”，支持并行子任务、依赖阻塞与人类提问节点。与常见框架相比，它强调让 Agent 自主决定拆解结构，而非开发者提前写死路径。当前更多是架构理念与早期实现展示。
- 亮点：信息有限，保守判断——适合探索型任务编排，但进入生产前需重点验证可观测性、失败恢复与权限边界。

6) [Sandworm 风格 NPM 蠕虫：劫持 CI 并污染 AI 工具链（Socket）](https://socket.dev/blog/sandworm-mode-npm-worm-ai-toolchain-poisoning)
- 摘要：HN 讨论聚焦“AI 工具链供应链攻击面扩大”，即通过依赖与 CI 环节传播，最终影响模型开发与交付流程。该文章站点访问受限，公开可读细节不足，但议题本身与近期软件供应链风险趋势一致。对 AI 团队来说，风险不只在模型输出，更在训练/构建/发布链路。
- 亮点：信息有限，保守判断——应立即把 AI 项目纳入与核心业务同级的 SBOM、依赖签名与 CI 隔离策略。

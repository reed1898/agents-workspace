# 重新反思强势文化

《天道》中最核心阐述的一个概念：强势文化。强势文化最核心的是要尊重客观规律，而不是情绪。其反面的弱势文化就是靠文化，在家靠父母，出门靠朋友，靠上帝靠菩萨靠皇恩，总之靠什么都行，就是不靠自己。都是靠别人的施舍，不能做出自己的判断，错了还要怨对方。

回想在Crypto的交易上，我就一直是一种弱势思维。

依靠 KOL 喊单。跟随大宇的喊单，提到某些 MEME 币就冲进去，近期的币安人生之类的，之前的各种 AI Agent 的币，结果都死的很惨。还有之前看Mark的喊单，跟个 1 万刀冲进去，大都亏一半出来。老陆说的 Cards，买完也腰斩在腰斩，搞得现在都不想理。还有之前别人说的 DePin，Mobile，所谓的北美移动，跌掉 90%。

觉得跟着 UV 混能赚到钱，UV 概念版买了一堆基本是赔钱的，UX 的参加 UniCall 也是赔钱的，sb 的 Fair3，跌了一大半，累计亏损应该是在 20 万美金。

各种经历证明，靠着二手消息，内幕消息太不靠谱。投机一事还是得靠自己，认真学习投机技术，做深深度研究才是唯一正确的路。

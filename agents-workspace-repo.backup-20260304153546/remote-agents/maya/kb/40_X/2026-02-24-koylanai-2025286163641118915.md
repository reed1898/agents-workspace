## 标题
The File System Is the New Database: How I Built a Personal OS for AI Agents

## 核心摘要
作者提出并实践了一套“Personal Brain OS”：
- 用 **Git 仓库 + 文件系统**（Markdown/YAML/JSONL）作为 AI 的长期上下文与记忆层；
- 用 **模块化 + 渐进加载（Progressive Disclosure）** 控制上下文体积，避免一次性塞满 prompt；
- 用 **Skill 系统**把流程固化（内容生产、研究、关系管理、周复盘等）；
- 强调 **Context Engineering > Prompt Engineering**：关键不是一句 prompt，而是信息架构。

关键设计点：
1. 三层加载：路由文件（常驻）→ 模块说明（按需）→ 数据文件（最后加载）。
2. 指令分层：仓库级 / 中枢级 / 模块级，避免规则冲突。
3. 文件即数据库：JSONL 记日志（追加写），YAML 放配置，Markdown 放叙事与模板。
4. 技能化流程：自动加载参考技能 + 手动触发任务技能（slash command）。
5. 失败复盘：记录 decisions/failures/experiences，让 AI 学你的“判断”，不只是记事实。

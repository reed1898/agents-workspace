# OpenClaw 生态知识库（持续积累）

目标：沉淀 OpenClaw 生态中的玩家、产品方向、关键信号与判断变化。

## 目录约定
- `players/`：玩家画像（公司/个人、定位、产品、进展）
- `signals/`：每日信号（新闻、发布、融资、功能变更、社区动向）
- `weekly/`：周度观察（趋势、分层、变化、风险）
- `sources/`：原始来源快照（链接、引用、截图说明）

## 记录规范
每条记录尽量包含：
1. 时间（UTC+8）
2. 事实（发生了什么）
3. 证据（链接/截图/日志路径）
4. 判断（为什么重要）
5. 置信度（高/中/低）

## 输出原则
- 先事实，后判断。
- 不追求全，追求可复盘与连续更新。
- 每日新增 3-5 条有效信号，周更一份结构化总结。

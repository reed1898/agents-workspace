  亮点：若你做 B2B AI，下一阶段护城河是“能否在高安全环境稳定上线”，而不只是 API 性价比。

- 标题（含链接）：[OpenAI raises $110B on $730B pre-money valuation](https://news.ycombinator.com/item?id=47181211)
  摘要：超大规模融资把市场预期进一步推向“算力、模型、应用生态全栈竞争”，同时也抬高了资本效率与商业化兑现压力。HN 讨论里既有对增长潜力的乐观，也有对估值泡沫与回报周期的担忧。对创业团队而言，这会加速头部资源集中，也会倒逼细分场景跑出真实收入。
  亮点：融资越大，越要求应用层团队尽快证明“可复用场景 + 真实付费”而非概念演示。

- 标题（含链接）：[Use plain old REST instead of MCP](https://news.ycombinator.com/item?id=47185044)
  摘要：文章主张在部分场景中优先使用 REST 而非 MCP，核心论点是工程复杂度与可维护性权衡。它反映出 Agent 工程实践开始从“新协议热潮”回到“能否低成本稳定交付”的现实问题。当前互动数据不高，但议题具有长期工程价值。
  亮点：信息有限，保守判断：先用最小协议跑通价值，再在多工具编排阶段引入 MCP。

- 标题（含链接）：[Show HN: Recall – Persistent Memory for Claude Code via MCP Hooks](https://news.ycombinator.com/item?id=47189906)
  摘要：该项目把“持久记忆”作为 AI 编码助手的核心能力，通过 session-start / observe / pre-compact / session-end hooks 缓解上下文丢失问题。方案强调低侵入（脚本化 hooks）与可部署性（插件/自托管），贴近真实开发流程。当前仍属早期验证阶段，生产稳定性与团队协作边界有待进一步观察。
  亮点：信息有限，保守判断：记忆层是 2026 年 Agent 生产化的高价值模块，值得尽早做内部试点。

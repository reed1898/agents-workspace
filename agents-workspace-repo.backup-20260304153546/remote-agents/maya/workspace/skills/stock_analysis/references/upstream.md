# Upstream 对齐说明

上游项目：`https://github.com/ZhuLinsen/daily_stock_analysis.git`

## 对齐点

- 目标一致：围绕“股票分析”输出可执行结论。
- 本 skill 聚焦“单只股票分析”，方便被上层持仓总任务循环调用。
- 输出改为标准化 JSON + 可读文本，便于自动汇总。

## 差异说明

- 上游项目偏完整应用流程；本 skill 提供最小可运行入口，强调可集成性。
- 本 skill 增加 `--sample` 离线模式，应对依赖或网络不可用场景。
- 数据源默认 `yfinance`（可替换成内部行情源）。

## 后续可增强

- 接入上游更多基本面/财报维度
- 引入多模型总结器（如 Gemini/OpenAI）生成更细的投资备忘
- 输出统一 schema 版本号，便于上游编排器做兼容处理

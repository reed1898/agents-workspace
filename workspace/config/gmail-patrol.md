## 处理规则
1. 扫描所有未读
2. **超过 1 周的邮件：直接标已读，不处理不汇报**
3. 1 周内的邮件：逐封读取内容后再分类汇报（禁止只报发件人/标题）
4. 每封邮件必须给出：`内容摘要（2-4句）+ 动作标签`
5. 动作标签统一为：`需立即处理 / 今日可处理 / 仅阅读 / 可归档`
6. 对交易、账户、安全、合作、日程类邮件，必须补充：`关键点 + 风险点 + 建议动作`
7. 🔵 类邮件：通过 Codex 子任务读全文，提取中文摘要，并给出`1条最有价值观点 + 对 Reed 的价值`
8. 汇总时必须给出`今日 Top 3 最值得处理/阅读邮件`与理由
9. 有价值内容收录到知识库 shared/
10. 汇报完成后，全部标为已读

## 质量红线（不达标=巡检失败）
- 只列标题、不读正文
- Newsletter 未提供摘要，或单封摘要少于100字
- 缺少动作标签
- 交易/安全/账户邮件缺少风险判断
- 没有 Top 3 优先级结论

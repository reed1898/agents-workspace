### 配置流程（备忘）
1. 安装 gws: `npm install -g @googleworkspace/cli`（已装好 v0.3.4）
2. Google Cloud Console 创建项目 `gws-auth-489316`
3. 配置 OAuth consent screen（External, Testing 模式），**添加自己为 Test user**
4. 创建 OAuth Client ID（Desktop app），下载 client_secret.json
5. 文件放在 `~/.openclaw/config/gws/`，软链接到 `~/Library/Application Support/gws/client_secret.json`
   - ⚠️ macOS 上 gws 读的是 `~/Library/Application Support/gws/`，不是 `~/.config/gws/`
6. 登录: `gws auth login --scopes https://mail.google.com/`
   - ⚠️ `--scopes gmail` 简写无效，必须用完整 URL
   - ⚠️ 本机在国内，gws 直连 Google 会超时，需要走代理
7. **关键问题**: gws 自己换 token 时连不上 Google（被墙），所以用 curl 手动通过代理换 token
8. Token 存储: `~/Library/Application Support/gws/credentials.json`（手动写入）
9. 使用时通过 `GOOGLE_WORKSPACE_CLI_TOKEN` 环境变量传 access_token

### 最终方案
- 包装脚本: `~/.openclaw/workspace/scripts/gws-proxy.sh`
- 自动检测 QuickQ 代理端口（端口不固定）
- 自动用 refresh_token 刷新 access_token
- 所有 gws 操作都通过这个脚本调用
